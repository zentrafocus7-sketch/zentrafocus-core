**Title:** Correct Owner field on domain and template documents to reflect role, not just current holder
**Type:** Factual Update
**Decision:** constitution/GOVERNANCE.md's Authority Levels model explicitly distinguishes a level (a responsibility) from the person currently holding it, and states this collapse to one person at solo-founder stage is expected. Despite this, every domains/*/DOMAIN.md and templates/*.md file listed Owner as "Founder (Level 0)" — which is correct for constitutional material (Level 0 is non-transferable and is definitionally the Founder) but incorrect for domain and template documents, whose owning role per Governance's own table is Domain Owner (Level 2) and Maintainer (Level 1) respectively. Stating "Founder (Level 0)" on these documents risked a future reader inferring that routine domain policy or template changes require constitutional-tier (Level 0) approval, when Governance's change taxonomy actually requires only Level 2 or Level 1 approval for these.

This is corrected: all four domains/*/DOMAIN.md files now read "Domain Owner (Level 2) — currently Founder"; all four templates/*.md files now read "Maintainer (Level 1) — currently Founder." This is classified as a Factual Update per Governance Section 4's own example ("reassigning an owner"), applied in place.
