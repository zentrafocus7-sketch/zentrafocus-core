**Title:** Brand Visual System Policy
**Purpose:** Defines the standards a visual expression of ZentraFocus must satisfy. Does not restate the literal token values — those live in design-system/, per Single Point of Truth (Principle 2); this document states the rule those values must serve.
**Policy:** Visual style is dark, minimal, premium SaaS — never generic dashboards, never Notion-style layouts. Reference points for tone and quality bar: Linear, Stripe, Vercel, Arc Browser. Every downstream surface (website, HQ app, product delivery pages, marketing creative) must derive its colors, typography, and spacing from design-system/ directly rather than restating or approximating them independently. A visual asset that doesn't reference design-system/'s current values is non-compliant regardless of how close it looks.
