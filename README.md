# ZentraFocus Core

ZentraFocus Core is the governance layer of the ZentraFocus business — the single authoritative record of what has been decided, standardized, and committed to.

**Start here:** `constitution/MISSION.md`

**Read in this order:**

1. `constitution/MISSION.md` — what this repository is and why it exists
2. `constitution/PRINCIPLES.md` — the permanent rules every decision must obey
3. `constitution/GOVERNANCE.md` — who has authority and how change happens
4. `constitution/BLUEPRINT.md` — how this structure implements the three documents above

Everything else in this repository — `domains/`, `decisions/`, `registry/`, `archive/`, `design-system/`, `templates/` — is explained by those four documents. Nothing outside `constitution/` should be read before them.
